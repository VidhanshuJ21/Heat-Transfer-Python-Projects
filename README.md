# Heat-Transfer-Python-Projects# Heat Transfer – Python Projects

This folder contains two basic Python simulations for understanding heat conduction and temperature distribution. Results are visualised using Plotly.

## 1. 2D Steady-State Plate Conduction
Solves the 2D equation on a square plate using finite-difference method.

## 2. Transient Heat Transfer – Double-Pane Window
Models heat conduction through a glass–air–glass arrangement using an implicit finite-difference approach. The calculated temperature distribution is displayed as a heatmap.

## Requirements

Install Python and the required libraries:

```bash
pip install numpy plotly
```

## How to Run

1. Save each code in a separate Python file (or run it in a Jupyter Notebook).
2. Open a terminal in the project folder.
3. Run each file individually:

```bash
python plate_conduction_2d.py
python transient_heat_transfer.py
```

The numerical results will be printed, and an interactive Plotly temperature visualisation will open for each simulation.

## Learning Note

These are basic educational simulations developed to explore heat-transfer concepts and numerical methods. I used basic AI assistance to understand selected concepts and implementation details; the codes were not generated entirely by AI.
